# UI_CONTRACT_GAPS.md — daftar keputusan sebelum wiring
Audit ini membandingkan kebutuhan layar Master Spec/PRD dengan `phase0/openapi.phase0.json` v1.2 (63 operasi). Ini **bukan** persetujuan menambah endpoint atau business logic. Usulkan DTO/parameter minimal ke PO/BE, review keamanan/role, freeze OpenAPI, test, baru render. Tidak mengganti API contract. Design-only states boleh dibuat fixture di dev/test, production tidak memakai fake API. Jika P0 gap menghambat acceptance criteria, tandai blocker rilis, bukan menyatakan fitur selesai dengan tombol disabled.

Cross-cutting: `AUTH_SECURITY.md` provider setup, DTO validators, CSRF rotation, error normalization, capability vocabulary and integration tests must be completed in Phase 0B. Design uses no browser internal-service calls. For `POST /web-chat`, obey actual OpenAPI security/CSRF and provider policy after sign-off. Use safe server messages only; localized business reason contract should be verified. Program card territory label join from public territories requires approved read path. Official contact content, policy notice and text translations need PO verification, not model-invented government contacts. No additional URLs without approval. Any proposed feature in brief not backed by MS remains out of scope.
